Move My Account to Another Site or Device

Browser localStorage does NOT transfer between different website addresses or devices. If you open RIXO on a new hosted address or a new iPhone, it will start at $300 there unless you move your account with the steps below. Export here first, then import that file on the other site/device. The export contains only simulated account data, risk settings, and your journal note. It contains NO API keys, proxy credentials, or real account information — any credential-like fields in an import file are ignored.

Resetting clears this browser's locally stored simulation history. It does not affect any real account, because none is connected.
